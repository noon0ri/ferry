# Ferry Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 흩어진 Claude Code 세션을 한 목록에 모아 보여주고, 클릭 한 번으로 Terminal.app에서 재개시키는 macOS 메뉴바 앱을 만든다.

**Architecture:** SwiftPM 패키지 하나에 UI 없는 `FerryCore` 라이브러리와 SwiftUI `FerryApp` 실행 타깃을 둔다. 파싱·스캔·명령생성 로직은 전부 `FerryCore`에 있어 픽스처 파일만으로 테스트되고, UI는 그 위에 얇게 얹는다. 빌드된 실행 파일은 셸 스크립트로 `.app` 번들에 감싼다.

**Tech Stack:** Swift 6, SwiftPM, SwiftUI (`MenuBarExtra`), Observation (`@Observable`), Swift Testing (`@Test`/`#expect`), AppKit (`NSAppleScript`, `NSPasteboard`)

**Spec:** `docs/superpowers/specs/2026-08-30-ferry-design.md`

## Global Constraints

- 최소 macOS 버전: **macOS 14** (`@Observable`이 요구). `Package.swift`에 `platforms: [.macOS(.v14)]`
- Swift tools version: **6.0**
- 외부 의존성 **없음**. Foundation / SwiftUI / AppKit / Testing 만 사용
- 로그 루트: `~/.claude/projects/`. 이 경로 아래 파일을 **읽기만** 한다. 절대 쓰지 않는다
- 스캔 대상은 `<프로젝트디렉토리>/*.jsonl` (depth 1)뿐. `<세션id>/subagents/` 하위는 제외
- 그룹핑 키는 로그 내부 `cwd` 필드. 디렉토리명을 디코딩하지 않는다
- 파일은 꼬리 256KB만 읽는다. 실패 시에만 전체 읽기로 폴백
- 표시 규칙은 스펙 §4를 따른다 (프로젝트 `latestActivity` 내림차순, 세션 `modifiedAt` 내림차순, 기본 접힘 + 최상단 1개만 펼침, 60초 이내 활동은 초록 점)
- 커밋 메시지는 한국어로 작성한다

```swift
import Foundation

public struct Session: Identifiable, Equatable, Sendable {
    public let id: String
    public let logPath: URL
    public let cwd: String
    public let title: String
    public let gitBranch: String?
    public let modifiedAt: Date

    public init(id: String, logPath: URL, cwd: String,
                title: String, gitBranch: String?, modifiedAt: Date) {
        self.id = id
        self.logPath = logPath
        self.cwd = cwd
        self.title = title
        self.gitBranch = gitBranch
        self.modifiedAt = modifiedAt
    }
}

public struct Project: Identifiable, Equatable, Sendable {
    public let path: String
    public var sessions: [Session]

    public var id: String { path }
    public var name: String { Project.displayName(for: path) }
    public var latestActivity: Date {
        sessions.map(\.modifiedAt).max() ?? .distantPast
    }

    public init(path: String, sessions: [Session]) {
        self.path = path
        self.sessions = sessions
    }

    /// 경로의 마지막 성분을 표시 이름으로 쓴다.
    /// 디렉토리명(`-Users-seongbin-Codes-...`) 디코딩은 불가능하므로
    /// 반드시 로그 안의 `cwd` 값을 넘겨야 한다.
    public static func displayName(for path: String) -> String {
        var trimmed = path
        while trimmed.count > 1 && trimmed.hasSuffix("/") {
            trimmed.removeLast()
        }
        return (trimmed as NSString).lastPathComponent
    }
}
```

```swift
import Foundation

/// 임시 디렉토리에 jsonl 픽스처를 만들고 URL을 돌려준다.
func makeFixture(_ contents: String, name: String = "\(UUID().uuidString).jsonl") throws -> URL {
    let dir = URL(fileURLWithPath: NSTemporaryDirectory())
        .appendingPathComponent("ferry-tests-\(UUID().uuidString)")
    try FileManager.default.createDirectory(at: dir, withIntermediateDirectories: true)
    let url = dir.appendingPathComponent(name)
    try contents.write(to: url, atomically: true, encoding: .utf8)
    return url
}

/// 실제 로그와 같은 모양의 최소 세션 본문.
func sampleLog(sessionId: String = "01292266-bea7-439a-8174-de310dbb1f5f",
               cwd: String = "/Users/seongbin/Codes/enigma",
               gitBranch: String? = "main",
               title: String? = "Enigma 퍼즐 파이프라인 그룹4 실행",
               prompt: String = "handoff.md를 읽어라") -> String {
    let branchField = gitBranch.map { "\"\($0)\"" } ?? "null"
    var lines = [
        """
        {"type":"user","sessionId":"\(sessionId)","cwd":"\(cwd)","gitBranch":\(branchField),"timestamp":"2026-08-23T03:50:11.142Z","message":{"role":"user","content":"\(prompt)"}}
        """,
        """
        {"type":"assistant","sessionId":"\(sessionId)","cwd":"\(cwd)","gitBranch":\(branchField),"timestamp":"2026-08-23T03:50:20.000Z"}
        """,
    ]
    if let title {
        lines.append("""
        {"type":"ai-title","aiTitle":"\(title)","sessionId":"\(sessionId)"}
        """)
    }
    return lines.joined(separator: "\n") + "\n"
```

`Sources/FerryCore/SessionScanner.swift`:

```swift
import Foundation

public struct SessionScanner {

    public struct ParsedFields: Equatable, Sendable {
        public var aiTitle: String?
        public var cwd: String?
        public var gitBranch: String?
        public var sessionId: String?
        public var firstUserPrompt: String?
    }

    /// JSON Lines 텍스트에서 필요한 필드만 훑는다.
    /// - Parameter dropFirstLine: 파일 꼬리만 읽어 첫 줄이 잘렸을 수 있을 때 true.
    public static func parse(_ text: String, dropFirstLine: Bool) -> ParsedFields {
        var fields = ParsedFields()
        var lines = text.split(separator: "\n", omittingEmptySubsequences: true)
        if dropFirstLine && !lines.isEmpty {
            lines.removeFirst()
        }

        for line in lines {
            guard let data = line.data(using: .utf8),
                  let obj = try? JSONSerialization.jsonObject(with: data),
                  let record = obj as? [String: Any]
            else { continue }  // 손상 라인은 건너뛴다

            if let id = record["sessionId"] as? String {
                fields.sessionId = id
            }
            if let type = record["type"] as? String, type == "ai-title",
               let title = record["aiTitle"] as? String, !title.isEmpty {
                fields.aiTitle = title   // 나중 값이 이긴다
            }
            if let cwd = record["cwd"] as? String, !cwd.isEmpty {
                fields.cwd = cwd
            }
            if let branch = record["gitBranch"] as? String, !branch.isEmpty {
                fields.gitBranch = branch
            }
            if fields.firstUserPrompt == nil,
               let type = record["type"] as? String, type == "user",
               let message = record["message"] as? [String: Any],
               let prompt = extractText(from: message["content"]) {
                fields.firstUserPrompt = prompt
            }
        }
        return fields
    }

    /// content는 문자열이거나 `[{"type":"text","text":...}]` 배열이다.
    private static func extractText(from content: Any?) -> String? {
        var raw: String?
        if let string = content as? String {
            raw = string
        } else if let parts = content as? [[String: Any]] {
            let texts = parts.compactMap { $0["text"] as? String }
            raw = texts.joined(separator: " ")
        }
        guard let trimmed = raw?.trimmingCharacters(in: .whitespacesAndNewlines),
              !trimmed.isEmpty
        else { return nil }
        return trimmed
    }
}
```

```swift
    public static let tailBytes = 262_144

    /// 파일 끝에서 최대 `bytes`만큼 읽는다.
    /// - Returns: 읽은 텍스트와, 앞이 잘렸는지 여부.
    public static func readTail(_ url: URL, bytes: Int = tailBytes) throws -> (text: String, truncated: Bool) {
        let handle = try FileHandle(forReadingFrom: url)
        defer { try? handle.close() }

        let size = try handle.seekToEnd()
        let truncated = size > UInt64(bytes)
        let offset = truncated ? size - UInt64(bytes) : 0
        try handle.seek(toOffset: offset)
        let data = try handle.readToEnd() ?? Data()
        return (String(decoding: data, as: UTF8.self), truncated)
    }

    /// jsonl 파일 하나를 Session으로 바꾼다. cwd를 못 찾으면 nil.
    public static func scan(logPath: URL) -> Session? {
        guard let attributes = try? FileManager.default.attributesOfItem(atPath: logPath.path),
              let modifiedAt = attributes[.modificationDate] as? Date
        else { return nil }

        guard let tail = try? readTail(logPath) else { return nil }
        var fields = parse(tail.text, dropFirstLine: tail.truncated)

        // 꼬리에서 제목이나 cwd를 못 찾았고 파일이 잘렸다면 전체를 다시 읽는다.
        if tail.truncated && (fields.aiTitle == nil || fields.cwd == nil) {
            if let whole = try? String(contentsOf: logPath, encoding: .utf8) {
                fields = parse(whole, dropFirstLine: false)
            }
        }

        guard let cwd = fields.cwd else { return nil }

        let id = fields.sessionId
            ?? logPath.deletingPathExtension().lastPathComponent
        let title = fields.aiTitle
            ?? fields.firstUserPrompt
            ?? String(id.prefix(8))

        return Session(id: id, logPath: logPath, cwd: cwd,
                       title: title, gitBranch: fields.gitBranch,
                       modifiedAt: modifiedAt)
    }
```

```swift
import Foundation
import Observation

@Observable
public final class SessionStore {

    public private(set) var projects: [Project] = []

    private let root: URL
    private let scan: @Sendable (URL) -> Session?
    private var cache: [URL: (mtime: Date, session: Session)] = [:]

    public static var defaultRoot: URL {
        FileManager.default.homeDirectoryForCurrentUser
            .appendingPathComponent(".claude/projects")
    }

    public init(root: URL = SessionStore.defaultRoot,
                scan: @escaping @Sendable (URL) -> Session? = { SessionScanner.scan(logPath: $0) }) {
        self.root = root
        self.scan = scan
    }

    /// 로그 루트를 훑어 projects를 다시 만든다.
    /// mtime이 바뀌지 않은 파일은 캐시를 재사용한다.
    public func refresh() {
        let fm = FileManager.default
        guard let projectDirs = try? fm.contentsOfDirectory(
            at: root, includingPropertiesForKeys: [.isDirectoryKey],
            options: [.skipsHiddenFiles]
        ) else {
            projects = []
            return
        }

        var sessions: [Session] = []
        var freshCache: [URL: (mtime: Date, session: Session)] = [:]

        for dir in projectDirs {
            guard (try? dir.resourceValues(forKeys: [.isDirectoryKey]))?.isDirectory == true
            else { continue }

            // depth 1만 본다. <세션id>/subagents/ 는 자연히 제외된다.
            guard let files = try? fm.contentsOfDirectory(
                at: dir, includingPropertiesForKeys: [.contentModificationDateKey],
                options: [.skipsHiddenFiles]
            ) else { continue }

            for file in files where file.pathExtension == "jsonl" {
                let mtime = (try? file.resourceValues(forKeys: [.contentModificationDateKey]))?
                    .contentModificationDate

                if let mtime, let cached = cache[file], cached.mtime == mtime {
                    sessions.append(cached.session)
                    freshCache[file] = cached
                    continue
                }

                guard let session = scan(file) else { continue }
                sessions.append(session)
                if let mtime {
                    freshCache[file] = (mtime, session)
                }
            }
        }

        cache = freshCache
        projects = Self.group(sessions)
    }

    /// cwd로 묶고 스펙 §4의 표시 규칙대로 정렬한다.
    static func group(_ sessions: [Session]) -> [Project] {
        Dictionary(grouping: sessions, by: \.cwd)
            .map { path, group in
                Project(path: path, sessions: group.sorted { $0.modifiedAt > $1.modifiedAt })
            }
            .sorted { $0.latestActivity > $1.latestActivity }
    }
}
```

```swift
import Foundation
import AppKit

public protocol ScriptRunner: Sendable {
    func run(_ source: String) throws
}

public struct AppleScriptRunner: ScriptRunner {
    public struct Failure: Error {
        public let message: String
    }

    public init() {}

    public func run(_ source: String) throws {
        var error: NSDictionary?
        guard let script = NSAppleScript(source: source) else {
            throw Failure(message: "AppleScript를 만들 수 없습니다")
        }
        script.executeAndReturnError(&error)
        if let error {
            // 자동화 권한 거부(-1743)도 여기로 온다.
            throw Failure(message: error.description)
        }
    }
}

public enum LaunchOutcome: Equatable, Sendable {
    case launched
    case copiedToClipboard
}

public struct TerminalLauncher {

    private let runner: ScriptRunner
    private let copyToClipboard: (String) -> Void

    public init(runner: ScriptRunner = AppleScriptRunner(),
                copyToClipboard: @escaping (String) -> Void = TerminalLauncher.pasteboardCopy) {
        self.runner = runner
        self.copyToClipboard = copyToClipboard
    }

    public static func pasteboardCopy(_ text: String) {
        let pasteboard = NSPasteboard.general
        pasteboard.clearContents()
        pasteboard.setString(text, forType: .string)
    }

    /// 셸 단일 인용. 내부의 작은따옴표는 '\'' 로 끊어 붙인다.
    public static func shellQuote(_ s: String) -> String {
        "'" + s.replacingOccurrences(of: "'", with: "'\\''") + "'"
    }

    /// AppleScript 문자열 리터럴. 역슬래시를 먼저 치환해야 한다.
    public static func appleScriptQuote(_ s: String) -> String {
        let escaped = s
            .replacingOccurrences(of: "\\", with: "\\\\")
            .replacingOccurrences(of: "\"", with: "\\\"")
        return "\"" + escaped + "\""
    }

    public static func command(cwd: String, sessionId: String) -> String {
        "cd \(shellQuote(cwd)) && claude --resume \(sessionId)"
    }

    /// Terminal.app 새 탭에서 세션을 재개한다.
    /// 자동화 권한이 없으면 명령을 클립보드에 복사하는 것으로 폴백한다.
    @discardableResult
    public func launch(_ session: Session) -> LaunchOutcome {
        let command = Self.command(cwd: session.cwd, sessionId: session.id)
        let source = """
        tell application "Terminal"
            activate
            do script \(Self.appleScriptQuote(command))
        end tell
        """
        do {
            try runner.run(source)
            return .launched
        } catch {
            copyToClipboard(command)
            return .copiedToClipboard
        }
    }
}
```

```swift
    }

    private func binding(for project: Project) -> Binding<Bool> {
        Binding(
            get: { expanded.contains(project.id) },
            set: { isOn in
                if isOn { expanded.insert(project.id) } else { expanded.remove(project.id) }
            }
        )
    }

    /// 스펙 §4: 기본 접힘, 최상단 1개만 펼침. 앱 실행 중에는 사용자 선택을 유지한다.
    private func applyInitialExpansion() {
        guard !didSetInitialExpansion, let first = store.projects.first else { return }
        expanded = [first.id]
        didSetInitialExpansion = true
    }

    private func open(_ session: Session) {
        guard FileManager.default.fileExists(atPath: session.cwd) else {
            notice = "폴더가 없습니다: \(session.cwd)"
            return
        }
        switch launcher.launch(session) {
        case .launched:
            notice = nil
        case .copiedToClipboard:
            notice = "Terminal 제어 권한이 없어 명령을 복사했습니다"
        }
    }
}

private struct SessionRow: View {
    let session: Session
    let action: () -> Void

    private var isActive: Bool {
        Date().timeIntervalSince(session.modifiedAt) < 60
    }

    private var folderExists: Bool {
        FileManager.default.fileExists(atPath: session.cwd)
    }

    var body: some View {
        Button(action: action) {
            HStack(spacing: 8) {
                Circle()
                    .fill(isActive ? Color.green : Color.secondary.opacity(0.4))
                    .frame(width: 7, height: 7)
                VStack(alignment: .leading, spacing: 1) {
                    Text(session.title)
                        .lineLimit(1)
                    HStack(spacing: 4) {
                        Text(relativeTime)
                        if let branch = session.gitBranch {
                            Text("· \(branch)")
                        }
                    }
                    .font(.caption2)
                    .foregroundStyle(.secondary)
                }
                Spacer()
            }
            .contentShape(Rectangle())
            .padding(.vertical, 3)
            .padding(.leading, 4)
        }
        .buttonStyle(.plain)
        .opacity(folderExists ? 1 : 0.45)
        .help(session.cwd)
    }

    private var relativeTime: String {
        let formatter = RelativeDateTimeFormatter()
        formatter.unitsStyle = .short
        return formatter.localizedString(for: session.modifiedAt, relativeTo: Date())
    }
}
```

## Task 7: .app 번들과 자동화 권한

**Files:**
- Create: `Scripts/bundle.sh`
- Create: `README.md`

**Interfaces:**
- Consumes: `swift build -c release`가 만든 `FerryApp` 실행 파일
- Produces: `build/Ferry.app` — `LSUIElement`와 `NSAppleEventsUsageDescription`을 갖춘 번들

`swift run`으로는 Dock 아이콘이 뜨고 자동화 권한 설명 문구가 없다. 배포 가능한 형태로 만든다.

- [ ] **Step 1: 번들 스크립트 작성**

`Scripts/bundle.sh`:

```bash
#!/bin/bash
set -euo pipefail

APP_NAME="Ferry"
BUNDLE_ID="dev.seongbin.ferry"
VERSION="0.1.0"

cd "$(dirname "$0")/.."
swift build -c release

APP="build/${APP_NAME}.app"
rm -rf "$APP"
mkdir -p "${APP}/Contents/MacOS" "${APP}/Contents/Resources"

cp ".build/release/FerryApp" "${APP}/Contents/MacOS/${APP_NAME}"

cat > "${APP}/Contents/Info.plist" <<PLIST
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>CFBundleName</key>              <string>${APP_NAME}</string>
    <key>CFBundleDisplayName</key>       <string>${APP_NAME}</string>
    <key>CFBundleIdentifier</key>        <string>${BUNDLE_ID}</string>
    <key>CFBundleExecutable</key>        <string>${APP_NAME}</string>
    <key>CFBundlePackageType</key>       <string>APPL</string>
    <key>CFBundleShortVersionString</key><string>${VERSION}</string>
    <key>CFBundleVersion</key>           <string>${VERSION}</string>
    <key>LSMinimumSystemVersion</key>    <string>14.0</string>
    <key>LSUIElement</key>               <true/>
    <key>NSAppleEventsUsageDescription</key>
    <string>세션을 재개할 때 Terminal.app에 명령을 전달하기 위해 필요합니다.</string>
</dict>
</plist>
PLIST

codesign --force --deep --sign - "$APP" 2>/dev/null || \
    echo "경고: 코드 서명 실패. 자동화 권한이 매번 초기화될 수 있습니다."

echo "완료: ${APP}"
```
